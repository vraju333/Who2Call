# SafeCard V1 — local-first Android MVP

## Run
1. Open this `SafeCard` folder in Android Studio.
2. Install JDK 17 and Android SDK 35 if Android Studio prompts you. Gradle wrapper is not bundled; Android Studio can generate one or use installed Gradle 8.9.
3. Sync Gradle and run `app` on an Android phone (API 26+).
4. Grant Contacts permission. Choose a circle and check contacts. The first scan creates a baseline; later newly appearing contacts are identified as 'first seen in last 5 days'.
5. Enter a **long shared passphrase** (at least 12 characters; use a randomly generated multiword phrase), tap Encrypt and share, then select a trusted person's messaging app. Confirm receipt before tapping Mark delivered.
6. On another Android device, install the same app, choose **Trusted person**, select the received `.scard` file via Android file picker and enter the passphrase.

## Scope and limitations
- No backend, cloud database, login, or Google API key. Contacts are read from Android's Contacts Provider; Google sync is optional.
- Four circles: Family, Work, Friends, Playgroup. Selections and first-seen dates are stored only in local SharedPreferences. The app never transmits a file by itself.
- Sharing opens the Android chooser. 'Mark delivered' is **manual**; the app cannot know if the recipient received the file.
- Each circle uses its own file; **use a different passphrase for each recipient/circle**. A code shared with someone can be used to decrypt any file encrypted with that code.
- `SCARD1` format: 6-byte ASCII header, 16-byte random salt, 12-byte random GCM IV, AES-256-GCM ciphertext/tag. Key: PBKDF2-HMAC-SHA256, 210,000 iterations. Encryption is authenticated; no server-side key escrow or recovery. If the passphrase is lost, the file cannot be recovered.
- Daily WorkManager reminders are approximate and may be delayed by Android battery policies; they do not run at a guaranteed hour.
- The first contact scan does not infer historical creation dates; subsequent newly seen contact IDs count as 'recent', even if added through sync/import. Contacts with multiple numbers may yield multiple vCard entries.
- V1 decrypts only files generated by this app. It is not a general-purpose vCard importer; the `.scard` extension is encrypted, not a plaintext `.vcf`.
- This is an MVP, **not security-audited**. Shared passphrases should be exchanged out-of-band, not in the same message as the file. Contacts can be copied after unlock; old copies cannot be revoked.
- The current reader displays name and phone only; no email or calendar data.
- No app store publishing, automated delivery confirmation, accessibility audit, automated tests, or backup/restore yet.
